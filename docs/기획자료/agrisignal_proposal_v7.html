01프로젝트 개요

전국 공영도매시장의 농산물 가격과 거래량을 매일 수집하고 가격 상승·하락 품목을 찾는다. 담당자는 동일 품종과 등급의 가격 추이, 거래량, 출하지별 공급 상황과 외부 지표를 확인하고 검증된 다음 주 가격 전망을 참고한다.

항목기획 내용
프로젝트명AgriSignal
주제전국 농산물 가격 변동 분석 및 수급 위험 모니터링
핵심 사용자농산물 유통기업의 시장동향 분석 담당자
핵심 질문지금 어떤 품목의 도매가격이 크게 변하고 있으며, 거래량과 출하지 및 관련 외부 지표에 어떤 변화가 있는가?
분석 범위전국 공영도매시장 및 공식 분류상 농산물 전체
수집 기간완료 5개년(2021~2025년) 목표 및 2026년 이후 신규 자료. 실제 과거 조회 범위 확인 후 확정
데이터 갱신거래·기상 일별, 수출입 월별, 경유 조건부 일별
결과물가격 종합 현황, 품목 상세와 수급, 외부 요인, 가격 전망
완료 기준수집부터 품질 검사, 분석 마트, BI 게시까지 무인 배치. 반복 처리에서 중복 집계 없음. 예측은 평가 통과 시 게시
전국 수집 범위는 유지한다. 다만 모든 품목의 가격을 같은 기준으로 비교하거나 모든 품목에 머신러닝을 강제하지 않는다. 수집 범위와 분석 가능 범위를 구분한다.

02배경과 사용자 정의

농산물 가격은 계절에 따른 공급 변동과 기상, 출하 여건, 수입 및 비용의 영향을 함께 받는다. 가격과 거래량은 도매시장에서 조회할 수 있지만 가격 변화가 일상적인 계절 변동인지, 어떤 출하지의 거래량이 감소했는지, 외부 자료가 같은 시점에 어떤 변화를 보였는지를 확인하려면 여러 자료를 대조해야 한다.

페르소나 항목설계 가설
역할유통기업 시장동향 분석 실무자
업무일일 시장 동향 점검, 주간 구매회의 자료 작성
불편급등·급락 품목을 찾고 시장별 규격과 거래량, 기상 및 수출입을 따로 확인
필요한 결정추가 확인할 품목, 시장, 출하지 우선순위 선정
기대 효과반복 조회와 수작업 비교 감소, 판단 근거와 데이터 기준일 확인
제외 범위개별 기업 매입단가 및 재고·발주 최적화, 소비자 구매 추천, 가격 변동 원인 단정

페르소나는 실제 인터뷰로 검증한 결과가 아니다. 사용자 검증 시 같은 점검 과제를 기존 조회 방식과 대시보드 방식으로 수행해 소요 시간, 정답률, 근거 확인 누락을 측정한다. 사전에 시간 절감률을 제시하지 않는다.

참고 코드에서 확인한 구현AgriSignal의 처리 원칙
light_gbm.py는 train의 price를 목표값으로 지정한 뒤 price를 제외하지 않은 train을 모델에 전달현재 목표 가격은 입력에서 제거하고 과거 가격 시차만 사용. 전체 특징과 목표를 물리적으로 분리
같은 파일의 실제 학습 병합은 가격과 국내외 유가만 사용. 기상·무역·도매 인수는 병합에서 제외외부 데이터가 실제 모델에 입력됐는지 검사하고 변수 그룹별 기여를 검증
TradeDataServiceImpl.java는 월간 값을 각 날짜에 저장월별 통계의 원래 단위를 유지하고 예측 기준일에 공개된 자료만 결합
ProductDataServiceImpl.java는 결측 가격에 예측값 또는 다른 등급/일자의 값을 사용할 수 있음관측 결측과 미수집을 구분. 예측값을 실제값으로 저장하지 않고 등급 대체 금지
예측값의 산포로 상·하한을 계산별도 과거 예측 잔차로 보정하고 테스트 포함률·구간 폭을 검증
참고 프로젝트의 기능과 구현 방식은 공개 코드에서 확인했지만 실제 운영 성공률, API 데이터 보유량, 모델 성능은 확인하지 않았다. 코드를 그대로 복제하지 않는다.

Nongstradamus의 오늘·내일 추천을 그대로 도입하지 않는다. 휴장과 공표 시점 차이가 있는 도매시장에서는 최근 완료 주의 변화율을 기본 순위로 제공한다. 일별 차트에는 실제 거래일을 표시하며 결측일을 0으로 표시하지 않는다. 다음 주 전망 순위도 같은 목표 주와 기준일의 검증된 대표 규격만 비교한다. 상승·하락 순위는 별도로 제공하고 방향에 해당하는 품목이 없으면 공란 대신 해당 없음으로 표시한다.

09가격 및 수급 분석 방법

가격의 기준과 순위

원천 거래금액을 kg으로 환산할 수 있는 동일 행의 중량과 함께 집계한다. 동일 규격 s, 시장 범위 m, 기간 t에 대해 대표 가격을 계산한다.

P(s,m,t) = Σ 환산 가능 거래금액(원) / Σ 환산 중량(kg)

전국 가격은 시장별 단순 평균이 아니라 전국 동일 규격 거래금액 합을 중량 합으로 나눈 값이다. 품목별 대표 규격은 사전에 정한 과거 기준기간의 거래중량과 거래 연속성으로 선정하며 판본을 고정한다. 품종과 등급을 혼합해 가격 순위를 계산하지 않는다. 품목 전체 거래량은 규격별 환산 중량을 합산해 별도 표시한다.

변화율(%) = 100 × (이번 완료 주 가격 / 직전 완료 주 가격 − 1)

월~일 완료 주와 정확히 7일 이전 주를 비교한다. 최근 일별 관측 추이는 별도로 제공한다. 분모 0, 불완전 수집, 규격 변경, 소량 거래(실측 후 기준 확정), 전국 시장 패널 불일치 또는 환산 금액 커버리지 미달이면 순위에서 제외한다. 초기 환산 커버리지 기준은 95%로 두고 검증 후 조정한다.

계절성을 고려한 이상 신호

Z = 0.67449 × (현재 가격 − 과거 계절 중앙값) / MAD

비교 대상은 이전 연도 동일 ISO 주차 ±2주에 해당하는 같은 규격 및 시장 범위다. 과거 3개 연도 이상 및 12개 유효 주 이상을 초기 기준으로 하고 MAD가 0이면 미산출로 표시한다. Z ≥ 3은 상승 점검, Z ≤ −3은 하락 점검 후보로 표시한다. 임계값은 실제 경보 빈도와 사용성 평가로 검증하며 통계적 확률로 표시하지 않는다.

거래량과 출하지

지표산식 또는 집계해석
동일 규격 거래량Σ 환산 중량대표 가격과 같은 모집단의 물량
품목 전체 거래량모든 환산 가능 규격의 중량 합전체 관측 거래량, 가격 비교용 아님
출하지 비중출하지 kg / 해당 규격·시장 전체 kg미상 출하지 포함, 거래처 의존 구조
출하지별 증감현재 주 kg − 직전 주 kg어느 출하지의 물량 변화가 큰지 확인
정합성출하지별 증감 합 = 전체 증감중복 조인 및 누락 확인

도매시장 거래량은 전국 생산량이나 재고, 수요를 직접 측정한 값이 아니다. 공표 완료가 확인된 경우에만 실제 미거래를 0으로 처리하고 수집 실패는 NULL 또는 미제공으로 표시한다.

10연계 분석과 과학적 검증

기상 자료는 날짜만으로 결합하지 않는다. 출하지 코드와 공식 행정구역 및 대표 ASOS 관측소를 연결한 뒤 과거 거래중량 비중으로 가중한다. 미매핑 또는 미관측이 많은 경우 해당 분석을 보류한다. 수출입은 중복 없는 HS 세부코드를 유효기간에 맞게 연결하며 신선 농산물과 가공품은 분리한다. 월별 자료를 일별 관측치처럼 복제해 회귀하지 않는다.

사전 정의한 품목과 시차에서 계절 sin/cos와 과거 가격 변화 등을 통제한 주간 회귀를 수행하고 잔차 자기상관, 공선성, 이상치 민감도를 검토한다. 표본이 충분하면 HAC 표준오차 및 신뢰구간을 계산하고 여러 가설을 검정할 때 FDR 보정 또는 탐색 결과로 표기한다. 외부 요인의 결과는 인과관계나 가격 상승 기여율이 아니라 관련성으로 제공한다. 통계 모형은 근거와 표본 조건을 충족한 품목에만 수행하며 전국에 별도 회귀 테이블을 만들지 않는다.

11가격 전망과 모델 검증

주간 업무와 데이터 갱신 조건에 맞춰 다음 완료 주 평균가격을 전망한다. 전국 수집은 유지하고 품종·등급·규격별 이력, 거래 연속성 및 품질 기준을 충족한 시계열만 학습한다. 5년 주간 이력은 약 260개 관측이므로 대규모 원천 행수를 독립 시계열 표본 수로 해석하지 않는다.

실험모델 및 입력검증 목적
B0최근 완료 주 가격 유지단순 기준
B152주 전 가격계절 기준
M1Ridge: 이전 주 가격, 이전 4주 평균, 이전 물량, 계절 sin/cos가격·물량·계절 입력 검증
M2LightGBM: M1과 동일 입력, 얕은 트리 및 규제비선형 모델 추가 가치 검증
M3검증된 모델 + 기상기상 그룹 추가·제거
M4M3 + 공개 시점 복원 가능한 수출입, 선택 경유외부 데이터 추가·제거
게시 기준검증 기간의 기준 모델 대비 개선, 홀드아웃과 급등 구간 점검조건 미달은 미제공

예시 검증: 2021~2023년 훈련, 2024년 시간순 검증에서 모델·설정을 선택, 2025년 홀드아웃 평가. 모든 예측은 그 시점 이전 정보로 expanding 또는 rolling 방식 재학습한다. 최소 104개 훈련 주와 26개 평가 주를 초기 기준으로 둔다. MAE(원/kg), MASE, 급등 구간 MAE를 계산하고 기준 대비 초기 5% 개선 기준을 사전에 정한다. 시연은 MAE 중심이다. 실제 예측구간은 별도의 과거 잔차 자료로 보정하고 포함률과 폭을 검증한다.

예측에는 available_at ≤ as_of인 외부 데이터 판본만 사용한다. 과거 공개 당시 자료를 복원할 수 없다면 해당 자료는 설명용으로 제한하거나 회고 평가라고 명시한다. 미래 기상 관측치, 목표 주 거래량, 목표 가격은 입력에 포함하지 않는다. 정산 발표가 늦어 목표 주가 이미 시작됐다면 발행 시각을 표시하고 목표 주 자료를 학습 특징에서 제외한다.

시연에서 실제로 실행한 비교

합성 주간 자료 9,360행에서 3개 품목과 3개 시장, 시연 전체 범위를 합친 12개 시계열을 분석했다. 2024년과 2025년 예측은 각각 636건과 612건, 총 1,248건이다. 모델 설정을 고정하고 동일 입력으로 Ridge와 LightGBM을 비교했다. 외부 변수의 추가 성능은 실제 데이터 확보 후 검증하며 합성 시연에서는 계산하지 않았다.

합성 평가 CSV / 재현 코드 / 대시보드 시연. 실제 농산물 예측 성능은 미검증이다.

15개발 순서와 범위 통제

단계구현 산출물완료 기준
1. 데이터 가용성전국 시장 목록, 최근 30일 전수 범위 계측, 과거 연도 샘플, 단위 표본정산 또는 경매 중 운영 원천 확정
2. 수집 및 SilverAPI 배치, Raw 이력, 코드·단위 정제, 가격과 물량 표준화재수집 중복 0, 정정·삭제 반영
3. BI가격 순위, 상세·수급 View, 완료 주 마트핵심 사용자 질문 답변, 자동 갱신
4. 연계산지 기상과 수출입, 조건부 경유조인 커버리지·공개 시점 검증
5. ML 및 운영기준 모델·Ridge·LightGBM, 평가, 예측 게시, 장애 시연성능 검증 및 자동 배치 복구

기간을 조정할 수 있지만 시장 및 품목의 전국 수집 범위를 제한하지 않는다. 원천 증설, 복잡한 모델, 별도 앱 기능은 실제 사용자 질문에 필요한 경우에만 추가한다. AWS 비용은 S3 요청·보존 용량, Glue DPU 시간, Athena 스캔량, Step Functions 실행량, SageMaker 작업 시간, Quick Sight 이용료와 SPICE를 실측하여 산정한다.

팀 역할은 수집 및 운영, 정제와 품질, BI와 SQL, 통계 및 ML로 구분하고 원천 명세와 품질 기준을 공동으로 관리한다. 데이터 엔지니어링 결과물을 중심으로 평가하고 예측 정확도가 개선되지 않더라도 가격·수급 분석과 자동화가 완성되면 핵심 목표를 달성한다.
